# Tarea API

## Descripción

Este es un proyecto de API RESTful desarrollado con **Spring Boot** para gestionar tareas. Permite crear, leer, actualizar y eliminar tareas de una base de datos.

## Requisitos

Antes de ejecutar la aplicación, asegúrate de tener los siguientes requisitos instalados:

- **Java 17** o superior.
- **Maven** 3.8.1 o superior.
- **IDE** recomendado: IntelliJ IDEA o Eclipse.
- **Base de datos H2** (se utiliza en este proyecto de forma interna).
